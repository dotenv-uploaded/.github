# .env 올려버린 팀 — public organization profile

This repository holds the **public** profile shown on
[github.com/dotenv-uploaded](https://github.com/dotenv-uploaded).

- `profile/README.md`: the organization Overview
- `profile/assets/`: images used by the Overview

The Overview summarizes [`_FOLDING_`](https://github.com/dotenv-uploaded/_FOLDING_) and links only to
pages that are reachable without signing in. Product documentation is not duplicated here; it lives with
the code it describes.
